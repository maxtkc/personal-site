## Tech Stack

### Hardware

This website is hosted from a Lenovo Thinkpad T480 sitting on top of my mom's
desktop in Boston. Sometimes I gotta ask my mom to give my server a kick for me
to get it up and running.

### Containerization

[k3s](https://k3s.io/)! Deployed via [ArgoCD](https://argoproj.github.io/cd/)

See my [repo here for more](https://github.com/maxtkc/kcfam-infra)

### Git Hosting/CI/CD

This site's source is [on GitHub](https://github.com/maxtkc/personal-site).
GitHub Actions installs zola, builds the site and deploys it to GitHub Pages.

### Static Site Generation

I use [Zola](https://www.getzola.org/) with the
[Duckquill](https://duckquill.daudix.one/) theme.

### Why?

I dunno, it's pretty cool to run entirely my own stuff though!
